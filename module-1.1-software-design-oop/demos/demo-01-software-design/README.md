# Demo 01 — Software Design

## Objective

Demonstrate how software design improves code organization without changing program behavior.

## Files

- `bad_design.py` — Example with multiple responsibilities in a single function.
- `improved_design.py` — Refactored version where each function has a single responsibility.

## Learning Objectives

After completing this demo, you should understand:

- Why separating responsibilities improves software quality.
- Why code organization matters even for small programs.
- The difference between code that works and code that is well designed.

## Key Takeaway

Good software design is not about changing what a program does; it is about improving how the program is organized so it becomes easier to understand, maintain, test, and extend.
