# Professional Python & Software Engineering Foundations

## Overview

This repository contains the material developed during **Phase 01** of the **Software Engineer for Machine Learning & AI Engineers Roadmap**.

The objective of this phase is to build a strong foundation in Python, software engineering, object-oriented programming, clean code, testing, and software architecture before moving into production Machine Learning, MLOps, LLMs, and AI systems.

---

## Learning Objectives

- Professional Python programming
- Software Design
- Object-Oriented Programming (OOP)
- SOLID Principles
- Clean Code
- Refactoring
- Software Engineering Principles
- Testing Fundamentals
- Python Project Organization
